# Утилиты cat и grep

## Описание проекта

Реализованы пользовательские версии утилит `cat` и `grep` с поддержкой всех необходимых флагов и функционала в соответствии с GNU-стандартами.

---

## Утилита cat

- Поддержка всех стандартных флагов `cat` (включая GNU).
- Исходные, заголовочные и сборочные файлы находятся в `src/cat/`.
- Итоговый исполняемый файл: `src/cat/cat`.

---

## Утилита grep

- Поддерживаемые флаги: `-e`, `-i`, `-v`, `-c`, `-l`, `-n`, `-h`, `-s`, `-f`, `-o`, а также их комбинации (например, `-iv`).
- Регулярные выражения реализованы с использованием библиотек `pcre` или `regex`.
- Исходные, заголовочные и сборочные файлы находятся в `src/grep/`.
- Итоговый исполняемый файл: `src/grep/grep`.
